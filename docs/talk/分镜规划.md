## 素材制作清单（A 类仿真需渲染的段）

1. **opening_wide**：全景机位 az315，G1 完整跟踪一段走跑动作（10s）
2. **tracking_nice**：最流畅一段跟踪（选 LAFAN 简单片段 + ckpt_0002000）（12s）
3. **tracking**：普通跟踪（8s）
4. **actions_walk/turn/crouch**：三种动作各 4s 快剪素材
5. **fall**：摔倒镜头（用 smoke_micro 早期权重或人为扰动触发，6s）
6. **idle**：站立微动（循环用，6s）
7. **rollout**：跟踪 + 关节拖影/轨迹线叠加（后期在 Remotion 里画叠加层，8s）
8. **slow**：0.25 倍慢放段（渲染 4s × 4 帧率）
9. **multi**：多机位（正面/侧面/俯视）各 3s，供扉页循环

## C 类曲线数据提取

- 从 `logs/smoke_8g/tb/events*` 提取标量：wm_loss、critic_loss、success_rate（若有）
- 存 `supermimic_video/video/public/curves.json`（Remotion 读）
- 从 `logs/lafan_8g_v1/tb/events*` 提取正式训练前 2000 it 曲线（S70 用）

## B 类代码卡取材文件

- `src/supermimic/world_model/`：模型定义、FK 头、终止头
- `src/supermimic/envs/`：观测构建（heading）、奖励
- `src/supermimic/policy/`：MotionEncoder、critic
- `src/supermimic/training/`：训练循环、采样器
- `config.json`：所有配置行
